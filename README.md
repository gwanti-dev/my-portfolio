# 🌐 My Portfolio

HTML + CSS နဲ့ ရေးထားတဲ့ ရိုးရှင်းတဲ့ personal portfolio website။

## Live demo
GitHub Pages ဖွင့်ပြီးရင် ဒီလိပ်စာမှာ ကြည့်လို့ရမယ်:
`https://<your-username>.github.io/my-portfolio/`

## Files
| File | အလုပ် |
|------|------|
| `index.html` | Page structure (content) |
| `style.css`  | Design / colors / layout |

## How to view locally
`index.html` ကို browser နဲ့ double-click ဖွင့်ရုံပါပဲ။

## Publish with GitHub Pages
1. Repo → **Settings** → **Pages**
2. Source: **Deploy from a branch** → `main` → `/ (root)` → Save
3. ၁–၂ မိနစ်စောင့်ပြီး link ကို ဖွင့်ကြည့်ပါ
